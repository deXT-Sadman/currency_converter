# 💱 Currency Converter App (Flutter)

A simple and elegant **Currency Converter App** built using **Flutter**.
This app converts **USD to Bangladeshi Taka (BDT)** with a clean Material UI.

---

## 📱 Features

* Convert USD ➝ BDT
* Clean and minimal UI
* User input with validation support
* Responsive layout
* Built with Flutter Material Design

---

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material UI**
* **StatefulWidget (State Management)**

---

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/currency_converter.git
```

### 2️⃣ Navigate to project folder

```bash
cd currency_converter
```

### 3️⃣ Install dependencies

```bash
flutter pub get
```

### 4️⃣ Run the app

```bash
flutter run
```

## ⚙️ How It Works

* User enters an amount in **USD**
* On button click:

  * Input is parsed into a number
  * Converted using a fixed rate (1 USD = 122.73 BDT)
* Result is displayed instantly on screen

---

## ⚠️ Note

* This app uses a **fixed exchange rate**
* It does NOT fetch real-time data from an API
